# Growth Lab

Личная платформа развития: продукт, проджект-менеджмент, дата-аналитика и код.
Отдельный сайт внутри того же репозитория, что и портфолио. Открывается по адресу `/growth/`.

## Как устроено

Статический сайт без сборки и без сервера. Одностраничное приложение на нативных
ES-модулях с роутингом по хешу. Прогресс хранится в `localStorage` этого браузера
и никуда не отправляется — поэтому в настройках есть экспорт и импорт резервной копии.

```
growth/
  index.html                 — оболочка: сайдбар, топбар, контейнер вью
  assets/css/growth.css      — дизайн-система, светлая и тёмная темы
  assets/js/
    app.js                   — навигация, роутер, тема
    store.js                 — состояние и localStorage, XP, серия, карта активности
    srs.js                   — интервальные повторения, алгоритм SM-2
    ui.js                    — помощники: экранирование, модалки, тосты, теги
    views/                   — по файлу на раздел
  assets/data/               — весь контент, обычные JS-модули
```

## Как добавлять свой контент

Всё содержимое лежит в `assets/data/` обычными массивами — формат виден по существующим записям.

**Статья** (`articles.js`): `id`, `track` (`product` / `delivery` / `data` / `code`),
`title`, `summary`, `minutes`, `level`, `body` (HTML), `quiz`.

**Вопрос теста** — четыре типа:
- `one` — один ответ: `options`, `answer` (индекс), `explain`
- `multi` — несколько: `answer` — массив индексов
- `num` — число: `answer`, `tolerance`, `unit`, `explain`
- `open` — свободный ответ: `reference` (эталон для самопроверки)

**Задача SQL** (`sqltasks.js`): достаточно написать `solution`. Ответ проверяется
сравнением результата с эталонным запросом, поэтому способ решения может быть любым.
`ordered: true` — если порядок строк важен.

**Задача по коду** (`codetasks.js`): `starter`, `tests` (`args` / `expected`), `solution`.

Учебная база для SQL генерируется детерминированно в `db.js` — у всех она одинаковая,
поэтому задачи воспроизводимы.

## Локальный запуск

Нужен http — нативные модули не работают с `file://`. Подойдёт любой статический сервер:

```bash
python3 -m http.server 8765
```

Затем открыть `http://127.0.0.1:8765/growth/`.

(В этом рабочем каталоге есть ещё `.claude/serve.js` — то же самое на node,
но папка `.claude/` не попадает в репозиторий.)

## Зависимости

Одна: `sql.js` (SQLite, WASM) подтягивается с cdnjs при первом открытии раздела SQL.
Всё остальное — свой код. Остальные разделы работают без интернета.
